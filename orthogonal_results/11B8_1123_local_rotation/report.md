# 11B8局部曲率方向补偿试验

已接通静态重建的local_rot_ang/local_rot_region，并复用已有动态校正实现。该功能旋转选定区间的曲率向量后重新积分；全局rot_ang=0。校正角0时，24工况路径与原静态路径一致（1e-9 m容差）。

扫描end10/end15/end25/end35/end50/end65，各区间内搜索常数补偿角，以0°的8个半径平均形状误差最小为目标。候选中选择end35、+155.38°。这是同批数据诊断拟合，并非独立验证。该区间以最后一个实测点s=0.892 m为末端，从s=0.542 m开始选点；第一个被选实测点为s=0.575 m。PCHIP与空间滤波会影响边界邻域，因此不是对XYZ曲线硬切后旋转。

0°平均离平面距离由36.56降至21.20 mm；修正后仍有明显形状偏差。同一局部补偿用于120°会使结果变差，不应认为是通用参数。该试验选择起点以候选区间内的误差最小为准，并未证明真实扭转从该位置开始。

CLI追加：`--rot_ang 0 --local_rot_ang 155.38 --local_rot_region end35`。`[end35,end5]`表示只校正距最后实测点5～35 cm的区间。静态输出配置保存实际局部角度与区域，逐点曲率CSV同时保留原始与校正后方向角。

验证：局部补偿单元/积分测试2项通过，交错校准/静态/权重回归测试1项通过。
